# EyeTracker

Real-time eye gaze and attention tracking using OpenCV and MediaPipe Face Mesh.

## Features

* Face mesh visualization
* Iris tracking
* Detects gaze direction:

  * Looking at Camera
  * Looking Left
  * Looking Right
* Attention monitoring
* Triggers an event after 3 seconds of continuous eye contact

## Requirements

* Python 3.10+
* OpenCV
* NumPy
* MediaPipe 0.10.14

## Installation

```bash
pip install opencv-python numpy mediapipe==0.10.14

```

## Run

```bash
python main.py
```

Press `Q` to quit the application.
